# Media Studio Companion (Chrome MV3)

## Kurulum

1. Admin panelinde projeye gir → **Media Studio** → **Eklenti indir**
2. `chrome://extensions` → Geliştirici modu → **Paketlenmemiş öğe yükle**
3. İndirdiğin klasörü / zip’ten çıkan `media-studio` klasörünü seç
4. ChatGPT / Gemini / Google Flow sayfasında panel açılır
5. Media Studio hesabınla giriş yap, proje seç, prompt kopyala ve durum güncelle

Kısayol: `⌘⇧M` / `Ctrl+Shift+M` paneli aç/kapat.

## Notlar

- Service role veya OpenAI anahtarı eklentide yoktur.
- `config.js` indirme sırasında uygulama URL ve anon key ile doldurulur.
